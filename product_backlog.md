# Product Backlog — Habit Tracker

This product backlog contains all user stories for the Habit Tracker application, organized by feature and prioritized according to their assigned priority labels.

---

## 1. Login / Registration

### 1.1 Account Registration

**Description:** Allow users to create a new account by providing the required registration information.

**Labels:** **`enhancement`**, **`priority: high`**

### 1.2 Account Login

**Description:** Allow registered users to log in using their username and password.

**Labels:** **`enhancement`**, **`priority: high`**

### 1.3 Error Feedback on Login

**Description:** Display a clear error message when a user enters invalid login credentials.

**Labels:** **`enhancement`**, **`priority: high`**

---

## 2. Home Page

### 2.1 Display Weekly Progress

**Description:** Display the user's habit progress for each day of the current week.

**Labels:** **`enhancement`**, **`priority: high`**

### 2.2 View Welcome Message

**Description:** Display a personalized welcome message containing the user's name on the home page.

**Labels:** **`enhancement`**, **`priority: medium`**

### 2.3 View Completed Habits

**Description:** Display the habits that the user has completed on the home page.

**Labels:** **`enhancement`**, **`priority: medium`**

---

## 3. Menu / Navigation

### 3.1 Access Menu Options

**Description:** Provide a menu containing the main navigation options, including Profile, Habits, Reports, and Sign Out.

**Labels:** **`enhancement`**, **`priority: high`**

### 3.2 Navigate to Habits Page

**Description:** Allow users to open the Habits page from the application menu.

**Labels:** **`enhancement`**, **`priority: high`**

### 3.3 Sign Out from Menu

**Description:** Allow users to securely sign out from their account through the application menu.

**Labels:** **`enhancement`**, **`priority: high`**

### 3.4 Navigate to Profile

**Description:** Allow users to open their profile page from the application menu.

**Labels:** **`enhancement`**, **`priority: medium`**

---

## 4. Profile

### 4.1 View Personal Information

**Description:** Display the user's personal information, including name, username, age, and country.

**Labels:** **`enhancement`**, **`priority: high`**

### 4.2 Edit Personal Information

**Description:** Allow users to edit their personal profile information.

**Labels:** **`enhancement`**, **`priority: high`**

### 4.3 Save Updated Information

**Description:** Save changes made to the user's profile information and retain the updated values.

**Labels:** **`enhancement`**, **`priority: high`**

### 4.4 Update Name in Header

**Description:** Update the name displayed in the application header after the user changes their profile name.

**Labels:** **`enhancement`**, **`priority: medium`**

---

## 5. Habit Management

### 5.1 Add a New Habit

**Description:** Allow users to create and add a new habit to their habit list.

**Labels:** **`enhancement`**, **`priority: high`**

### 5.2 Delete a Habit

**Description:** Allow users to remove an existing habit from their habit list.

**Labels:** **`enhancement`**, **`priority: high`**

### 5.3 Personalize a Habit with Color

**Description:** Allow users to assign a color to a habit to make it easier to identify and personalize.

**Labels:** **`enhancement`**, **`priority: low`**

---

## 6. Reports

### 6.1 View Weekly Reports

**Description:** Provide a weekly report showing the user's habit progress and completion data.

**Labels:** **`enhancement`**, **`priority: high`**

### 6.2 Visualize Completed Habits

**Description:** Provide a visual representation, such as a chart, showing completed habits across the week.

**Labels:** **`enhancement`**, **`priority: medium`**

### 6.3 View All Habits

**Description:** Allow users to view all their habits, including both completed and incomplete habits, in the reports section.

**Labels:** **`enhancement`**, **`priority: medium`**

---

## 7. Notifications

### 7.1 Enable / Disable Notifications

**Description:** Allow users to enable or disable habit notifications.

**Labels:** **`enhancement`**, **`priority: high`**

### 7.2 Add Habits for Notifications

**Description:** Allow users to select which habits should generate notifications.

**Labels:** **`enhancement`**, **`priority: medium`**

### 7.3 Set Notification Times

**Description:** Allow users to configure when habit notifications should be delivered, such as morning, afternoon, or evening.

**Labels:** **`enhancement`**, **`priority: medium`**

---
